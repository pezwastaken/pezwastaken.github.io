I recently completed my MSc in Computer Science at the University of Parma, Italy. I’m interested in software verification, static analysis, and the low-level systems that benefit from them.

My thesis is on the static analysis of Java reflection via abstract interpretation, built on top of JLiSA. I'm now continuing to work on JLiSA for SV-COMP 2027.

Projects

JLiSA and SV-COMP 2027

Ongoing work on JLiSA, a static analyzer for Java based on abstract interpretation, built on top of the LiSA analysis library. It won 3rd place at the 2026 edition of the Competition on Software Verification (SV-COMP), where verification tools are compared on a large public set of benchmark programs.

Static analysis of Java reflection (MSc thesis)

Extended JLiSA to handle Java reflection with abstract interpretation, evaluated on the SV-COMP benchmarks. Implemented the most common reflection methods by closely mimicking the internal workings of reflection such as class loading and caching of reflection data (fields and methods) in the abstract world.

Finite automata index with fuzzy matching

A Rust library built around finite automata and Levenshtein automata. It includes a compressed binary serialization format, and the resulting files can be queried straight from disk through memory mapping (mmap).
